    # CutTime

## System rezerwacji usług

System internetowy umożliwiający klientom rezerwowanie wizyt w salonie fryzjerskim.

## Autorzy

- Dawid Tomaszewski
- Tomasz Talacha

## Tematyka

Salon fryzjerski.

## Technologie

- PHP
- HTML5
- CSS3
- JavaScript
- MySQL / MariaDB
- Git
- GitHub

## Funkcje systemu

### Klient
- rejestracja,
- logowanie,
- przeglądanie usług,
- wybór pracownika,
- wybór terminu,
- tworzenie rezerwacji,
- przeglądanie własnych rezerwacji,
- anulowanie przyszłych rezerwacji,
- edycja profilu.

### Pracownik
- logowanie,
- podgląd dzisiejszych wizyt,
- podgląd przyszłych wizyt,
- historia wizyt,
- podgląd szczegółów rezerwacji,
- zmiana statusu wizyty.

### Administrator
- dashboard,
- zarządzanie użytkownikami,
- zarządzanie pracownikami,
- zarządzanie kategoriami,
- zarządzanie usługami,
- zarządzanie dostępnością,
- zarządzanie rezerwacjami,
- statystyki.
